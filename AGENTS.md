# newstab-ai

Implementação do [TabNews](https://tabnews.com.br) para o [curso.dev](https://curso.dev), construída com agentes de IA.

## Stack

- Next.js (App Router)
- TypeScript
- Deploy na Vercel

## Comandos

- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build de produção
- `npm run start`: serve o build de produção

## Convenções

- Interface e conteúdo em português do Brasil (`pt-BR`).
- `.vercel/` e `.env*` estão no `.gitignore`. Nunca commitar variáveis de ambiente.
